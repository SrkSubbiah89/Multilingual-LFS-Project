\section*{B.2 --- SemanticRelationEngine (illustrative summary)}
\begin{lstlisting}[breaklines=true,caption={SemanticRelationEngine configuration, verified values.}]
name: semantic_relation
approach: >
  Deterministic, hand-built ISCO<->ISIC and ISCO<->ISCED crosswalk tables.
  NOT sourced from an official ILO/UNESCO correspondence document -- a
  real search of the complete ISCO-08 Volume I document found no such
  table exists.
weights: {isic: 0.55, isced: 0.45}  # applied only when BOTH available;
                                      # single-standard and neither-available
                                      # cases use a different, documented
                                      # fallback (see Chapter 3)
partial_credit: +0.15 * n_moderate_violations * (1 - raw_score)
is_coherent_threshold: 0.70
severity: gap-based (LOW <=1 level, MODERATE =2, HIGH >2 outside expected
          range) -- a SEPARATE mechanism from the confidence-adjustment
          bands below, not derived from them
confidence_adjustment: {>=0.90: +0.10, >=0.70: +0.05, >=0.50: -0.05, else: -0.20}
submajor_strict_rules:
  "22": {isic_required: "Q", isced_min: 7}   # Health Professionals
  "25": {isic_preferred: "J"}                 # ICT Professionals
  "11": {isced_min: 6}                        # Chief Executives
validation: 61-case set, 0 mismatches; HIGH-severity HITL escalation
            verified 3x, 100%/15 escalated, 0%/46 non-HIGH escalated
\end{lstlisting}

\section*{B.3 --- ValidationAgent (verified rules)}
\begin{lstlisting}[breaklines=true,caption={ValidationAgent rules, confirmed directly against the live source.}]
name: validation_agent
rules:
  R01: Required fields (employment_status, industry) must be present
  R02: hours_per_week must be parseable as a number
  R03: hours_per_week must be in [1, 168]
  R04: hours_per_week > 80 -> warning (outlier)
  R05: Unemployed + non-empty job_title -> contradiction
  R06: Unemployed + hours_per_week > 0 -> contradiction
  R07: Not-in-labour-force + non-empty job_title -> contradiction
  R08: full_time + <20 hours/week -> warning
  R09: part_time + >=35 hours/week -> warning
  R10: Employed + 0 hours/week -> error
\end{lstlisting}
\textbf{This replaces the original draft's ten rules}, which described a
different, fabricated set (a wage gate, platform-worker rules, an "F3"
not-in-labour-force re-routing rule) that does not exist in the real
\texttt{ValidationAgent}. The ten rules above were confirmed by reading
\texttt{backend/agents/validation\_agent.py} directly.

\label{app:sre-demo}

%% The original draft's Appendix C showed a "10-case demo output" whose

The Semantic Relation Engine's crosswalk logic was validated on a 61-case
set with \textbf{zero mismatches} between expected and computed coherence
classifications. Separately, HIGH-severity escalation to the live HITL
queue was verified three times against the real
\texttt{/survey/sessions/\{id\}/message} endpoint:

\begin{lstlisting}[breaklines=true,caption={HIGH-severity HITL escalation, three independent runs against the live endpoint.}]
Run 1: 15/15 HIGH-severity cases escalated (100%); 0/46 non-HIGH escalated (0%)
Run 2: 15/15 HIGH-severity cases escalated (100%); 0/46 non-HIGH escalated (0%)
Run 3: 15/15 HIGH-severity cases escalated (100%); 0/46 non-HIGH escalated (0%)
\end{lstlisting}

Byte-identical results across all three runs. A worked example of the real
scoring formula (Chapter~\ref{chap:architecture}), for a case with both
ISIC and ISCED data available:

\begin{lstlisting}[breaklines=true,caption={Worked example of the real SRE formula.}]
Occupation: ISCO 2211 (Generalist medical practitioners)
Industry:   ISIC section Q (Human health and social work)
Education:  ISCED level 7 (Master's or equivalent)

score_ISIC  = 1.0   (major group 2 compatible with section Q)
score_ISCED = 1.0   (level 7 within expected [6,8] range for major group 2)

raw_score = 0.55 * 1.0 + 0.45 * 1.0 = 1.00
moderate_violations = 0  -> no partial-credit adjustment applied
score = 1.00
is_coherent = (score >= 0.70) = True
confidence_adjustment = +0.10   (score >= 0.90 band)
\end{lstlisting}

The real bilingual explanation text, confirmed directly from
\texttt{semantic\_relation.py}'s own \texttt{\_build\_explanations()}
method (not reconstructed or invented), for a coherent (score $\geq 0.90$)
case:

\begin{lstlisting}[breaklines=true,caption={Real EN+AR explanation text, verbatim from the live source.}]
EN: "Strong semantic alignment: occupation ({major_label}), industry
({isic_label}), and education ({isced_label}) are fully consistent
according to ILO ISCO-ISIC-ISCED crosswalk tables. Classification
confidence boosted by +{N}0%."

AR: "تطابق دلالي قوي: المهنة والصناعة والتعليم متسقة تماماً وفق جداول
التقاطع الدولية ILO. تم تعزيز ثقة التصنيف."
\end{lstlisting}

\textbf{A genuine, newly-noticed discrepancy, disclosed here rather than
silently left in place}: this real, live explanation string itself says
``according to ILO ISCO-ISIC-ISCED crosswalk tables,'' which is not
accurate given Chapter~\ref{chap:architecture}'s own finding that no such
official ILO table exists and the real crosswalk is hand-built. This is a
real wording issue in the production system's own generated text, found
while writing this appendix, not a documentation-only error --- flagged
here as a concrete, actionable item (correct or remove that phrase in
\texttt{\_build\_explanations()}) rather than left unmentioned because it
falls outside this thesis-correction task's original scope.

\noindent\textbf{Status note:} As of the writing of this thesis, \textbf{no
participant recruitment, pilot study execution, or data collection has been
conducted}, and the study had not been submitted for institutional ethics
approval. The information below represents the planned protocol only.

\begin{itemize}
  \item \textbf{Purpose:} Evaluating an AI-assisted system for conducting
  employment surveys in English, Arabic, Urdu, Hindi, and Tagalog.
  \item \textbf{What participation would involve:} Completing a Labour Force
  Survey via either the conversational AI interface or a traditional
  interviewer-administered survey, followed by a brief satisfaction
  questionnaire.
  \item \textbf{Voluntary participation:} Participation would be entirely
  voluntary, with withdrawal possible at any point.
  \item \textbf{Confidentiality:} Responses would be pseudonymised.
  \item \textbf{No real-world consequences:} Responses would not be shared
  with any government agency, employer, or authority, and would not
  influence any benefit, visa, or employment decision.
\end{itemize}
